**Official software releases and distribution**

## Available Products

Northline helps users manage social media publishing workflows, prepare content, schedule posts, and streamline supported social channel activities from a centralized application.

- **Latest stable release:** See the [Northline Releases](https://github.com/HeuristicArtificialIntelligence/Product-Releases/releases?q=northline)

### Other Products

Additional Hai7 products are distributed through this repository. Each product has its own release entries, version identifiers, downloadable assets, and product-specific installation instructions.

Browse the [complete release history](https://github.com/HeuristicArtificialIntelligence/Product-Releases/releases) to locate a product and its available versions.

## Download and Installation

1. Open the release history linked above.
2. Locate the release for the required product.
3. Select the required stable version.
4. Review the release notes and system requirements.
5. Download the explicitly named installation package.
6. Follow the installation instructions provided for that product.

Download only the assets associated with the intended product and version. Do not treat GitHub's automatically generated source-code archives as the product installer unless the release documentation explicitly says to do so.

## Versioning and Releases

Each product follows independent version numbering using a product-prefixed Git tag.

Examples:

- `northline-v1.4.0`
- `northline-v1.4.1`
- `other-product-v1.0.0`

Release notes identify the applicable product, version, changes, compatibility information, and installation considerations.

Stable releases are intended for their documented use cases. Prerelease or testing builds, when published, are identified accordingly.

## Package Integrity and Security

Where provided, release packages include checksums to help verify file integrity after downloading.

Verify downloaded packages against the checksum supplied with the corresponding release before installation.

Do not publish credentials, private keys, API tokens, customer data, or confidential configuration files in release assets.

To report a security vulnerability, contact Hai7 through an officially verified security or support channel rather than publishing sensitive exploit details in a public issue.
